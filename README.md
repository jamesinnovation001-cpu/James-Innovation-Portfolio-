# James Innovation Portfolio

Responsive portfolio website for James John Victor / James Innovation.

## Pages
- Home
- About
- Services
- Testimonials / Reviews (authentic-review empty state)
- Contact
- Custom 404 fallback

## Deploy
This is a static website. Import the repository into Vercel and set the framework preset to **Other** with no build command and no output directory. Vercel serves `index.html` and uses `vercel.json` for route rewrites.
